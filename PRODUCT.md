# Product

## Platform
web

## Users
The site addresses developers evaluating memory for AI agents. Audience inferred from the public README and the request to publish a project site.

## Product Purpose
bigfeels provides portable local memory with source evidence and explicit lifecycle operations. The site explains the mechanism and directs visitors to installation and source code.

## Capabilities and Constraints
The Python engine requires Python 3.11+ and SQLite FTS5. It has no mandatory third-party runtime dependencies. CLI, stdio MCP, authenticated loopback HTTP, and a local browser workspace are supported. Hermes and OpenClaw adapters can participate in automatic capture. Generic MCP does not imply automatic capture. Queued extraction needs a provider. The preview is installed from source, not a package registry. Scope boundaries are not OS sandboxes. Local storage does not imply that an optionally configured remote extraction provider never receives data.

## Brand Commitments
Use the lowercase name bigfeels. The package and command are bigfeels-mem. The user requested a responsive, modern, polished GitHub Pages site with a brand logo and icon. Copy uses direct human English, no em dashes, rhetorical parallelisms, inflated claims, invented testimonials, or filler. The user authorized independent creation and publication.

## Evidence on Hand
README.md, INSTALL.md, docs/CONTRACT.md, docs/advanced.md, and source code. Examples on the website are synthetic and labelled. No metrics or testimonials are provided.

## Product Principles
Explain the evidence relationship clearly. Keep installation honest and runnable. Preserve privacy boundaries. Keep the website independent of the memory engine.
