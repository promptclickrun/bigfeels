# Mnemosyne v1.3 import

Implements the repository portion of [issue #3](https://github.com/promptclickrun/bigfeels/issues/3). The user requested implementation, validation, and merge. Actual default-profile rollout requires access to the source export and Hermes runtime; neither is in this cloud checkout.

Use the documented v1.3 JSON export from `mnemosyne-memory==3.15.1`. Its wheel SHA-256 is `bc79a6277d2195bba59123292924e8ff5421357c58ee543a23054b8dd97d7484`; source contracts are `mnemosyne/core/memory.py:export_to_file`, `beam.py:export_to_dict`, and `canonical.py:export_all`. Supporting this export satisfies the issue's export-or-snapshot criterion. Do not open or modify the original Mnemosyne database.

## Contract

- Python 3.11+, no mandatory third-party runtime dependencies.
- Import working, episodic, legacy, and canonical rows, including canonical history. Reject malformed or unsupported exports before creating the destination.
- Preserve exact source rows as evidence, exact authored content, original IDs, session/scope signals, timestamps, validity, provenance, and canonical versions. Deterministic namespaced IDs prevent table/ID collisions. Never promote imported outcomes to verified or attested.
- Embeddings, scratchpad, consolidation/audit/sync logs, triples, annotations, and derived indexes are excluded as user memories; disclose excluded section counts.
- Global rows use the explicitly selected destination space. Session and canonical-owner rows use separate deterministic spaces. Retain source signals in evidence and list the resulting spaces in the private receipt. Expanding runtime access to those spaces is a separate reviewed configuration choice.
- Convert aware timestamps to UTC. Naive timestamps require an explicit source timezone; reject ambiguous/nonexistent local times. Preserve the original text in evidence.
- Link source supersession and canonical versions without crossing scopes. Reject missing/ambiguous references, duplicate IDs, and inconsistent history rather than silently losing lineage.
- The importer runs locally, without models, extraction jobs, credentials, or network calls. It imports into an empty destination in one transaction; a repeated identical import verifies every destination row and is a no-op. Changed/corrected/deleted destinations are never overwritten or resurrected.
- Receipt records counts, source and target SHA-256 fingerprints, old/new IDs, and scope mapping, without source content. File publication is private and atomic. A missing receipt after a crash can be regenerated by verified replay.
- Dry-run validates and returns counts/fingerprints without creating destination files. Never overwrite the source or an unrelated receipt.
- Document supported Hermes user-plugin installation, default-profile-only activation, separate backups, count/recall verification, and rollback to the untouched Mnemosyne database and provider.

## Validation

Synthetic export fixtures cover fidelity, temporal and scope behavior, exclusion, repeat imports, receipt recovery, invalid input, changed destinations, deleted-record replay, and atomic rollback. Verify the installed wheel, native plugin loader, full Python/Node suites, replay, and builds. Live migration/cutover is not claimed without the real source/profile evidence.
