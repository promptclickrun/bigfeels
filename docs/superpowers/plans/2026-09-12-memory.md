# bigfeels Implementation Plan

> Historical implementation plan. Worker instructions and phase ownership below are non-normative; use [../../CONTRACT.md](../../CONTRACT.md) and the root documentation for current behavior.

> **For agentic workers:** Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Deliver a runnable local memory product with tested continuity across agent adapters.
**Architecture:** SQLite evidence and knowledge store; durable model queue; authenticated
HTTP and MCP interfaces; thin lifecycle adapters; local inspection UI.
**Tech Stack:** Python >=3.11 standard library, SQLite FTS5, Node >=22 for OpenClaw.
**Spec:** ../specs/2026-09-12-memory-design.md

## Global Constraints

On-device storage; hosted models optional; zero mandatory runtime dependencies.
API contract: ../../CONTRACT.md. Never alter existing host configurations or publish.
New independent repository on feat/initial-release; no existing worktree to protect.

## Task 1: durable memory core (root)
Files: src/bigfeels_mem/store.py, schema.py, retrieval.py, privacy.py; tests/test_store.py.
Consumes source events; produces Store.dispatch per contract. Write tests for
replay, authorization, correction, time, conflicts, provenance, forgetting,
queue recovery and export/restore. Run `PYTHONPATH=src python3 -m unittest discover -s tests -v`
before implementation, implement transactional storage, rerun until passing.

## Task 2: service, CLI, MCP and inspection UI (interface worker)
Files: src/bigfeels_mem/{server,cli,mcp,client}.py, static/*; tests/test_interfaces.py.
Consumes Store contract; produces authenticated HTTP/MCP API, CLI and safe UI.
Tests first: bearer scope, invalid input, browser origin protection, real HTTP
roundtrip, MCP stdio handshake and tools, CLI init/pair/export/restore.
Implement then execute unittest, report precise integration limits.

## Task 3: host adapters (adapter worker)
Files: adapters/hermes/*, adapters/openclaw/*, tests/test_adapters.py, docs/compatibility.md.
Consumes HTTP contract; produces official host plugin registrations and lifecycle
capture/recall. Inspect upstream contracts read-only; test lifecycle source role,
session identity, replay, timeout, scope, nonprimary context and prefetch isolation.
Run tests RED before implementation and GREEN after; no live host installs.

## Task 4: model processing and evaluations (root)
Files: providers.py, tests/test_providers.py, benchmarks/*.
Implement strict structured extraction, configurable hosted embeddings, bounded
timeouts, failure recovery, deterministic replay metrics comparing no memory,
Markdown and hybrid baselines. Test using local HTTP fixture (no paid API).

## Task 5: integrated verification and handoff
Files: README.md, LICENSE, docs/operations.md, docs/verification.md.
Build installable wheel, run isolated CLI/service/MCP and cross-adapter scenarios,
browser QA, all tests, privacy and concurrency review. Record exact results and
unverified host runtime/hosted model boundaries. Commit owned work locally.
